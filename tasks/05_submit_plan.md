### 步骤1：项目概要介绍撰写

| 步骤 | 内容 | 字数 | 工时 |
|------|------|------|------|
| 1.1 | 确定文档结构 | - | 0.5h |
| 1.2 | 撰写项目背景与意义 | ~300字 | 1h |
| 1.3 | 撰写核心价值主张 | ~300字 | 1h |

| 1.6 | 撰写团队介绍 | ~200字 | 0.5h |
| 1.7 | 格式调整（楷体小四/A4） | - | 0.5h |
| 1.8 | 导出PDF | - | 0.5h |

**项目概要结构**：
```
一、项目背景与意义
   - 大学生职业规划痛点

   - 结构化画像
   - 可解释评分

   - 系统架构图

   - 差异化亮点

   - 团队成员
   - 分工
```

## 4. 验收标准

### 项目概要
- 字数：1200-1500字
- 格式：A4，楷体小四号
- 文件：PDF，≤10MB
- 5章节完整

### PPT
- 页数：≤20页
- 文件：≤50MB
- 格式：PPT或PDF

### 演示视频
- 时长：≤5分钟
- 文件：MP4，≤100MB
- 内容：完整演示核心流程
