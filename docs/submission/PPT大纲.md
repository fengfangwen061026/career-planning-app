# 基于AI的大学生职业规划智能体 —— PPT大纲（10-12页）

## 第1页：封面
- 项目名称：基于AI的大学生职业规划智能体
- 副标题：第17届中国大学生服务外包创新创业大赛 A13 赛题
- 团队名称、学校、指导老师、答辩日期

## 第2页：痛点与机遇（背景）
- 高校学生职业规划普遍存在 4 个问题：认知模糊、信息不对称、指导不足、规划难落地
- 传统指导方式以经验判断为主，缺少数据驱动和连续跟踪
- 机会点：AI + 招聘数据 + 可视化分析可形成个性化职业规划闭环

## 第3页：产品全景（核心流程）
- 流程图：简历上传 → AI解析 → 学生画像 → 岗位匹配 → 职业报告 → 图谱展示
- 核心数据规模：9958 条 JD、51 类岗位画像
- 双端协同：学生移动端使用，Admin 端管理与展示

## 第4页：学生画像模块
- 截图：学生画像页
- 展示内容：学校专业、技能条、项目/实习、证书荣誉、软素养、完整度
- 亮点：支持简历解析后自动生成，也支持对话式补全

## 第5页：人岗匹配（四维评分）
- 截图：匹配详情页
- 四维模型：基础要求 / 技术技能 / 职业素养 / 发展潜力
- 展示差距清单：缺什么、为什么扣分、建议如何补齐

## 第6页：五章职业报告
- 截图：报告生成页（SSE 流式）
- 五章结构：优势总结 / 岗位分析 / 行动计划 / 路径规划 / 评估周期
- 输出价值：不仅给结果，还给节奏、资源和复盘节点

## 第7页：职业图谱可视化
- 截图：岗位图谱（Admin端）
- 展示方式：按职级分层的岗位网络
- 说明内容：垂直晋升路径 + 横向换岗路径 + 关系强度

## 第8页：技术架构
- 前端：React + TypeScript 双端
- 后端：FastAPI + PostgreSQL 16 + pgvector
- AI：OpenAI 兼容 LLM 接口 + Embedding Provider + SSE 实时返回
- 工程特点：模块化服务、统一模型调用封装、可导出报告

## 第9页：准确率验证（赛题硬性指标）
- 岗位画像准确率验证思路：人工抽检 + 结构字段对齐
- 学生画像准确率验证思路：简历字段抽取比对 + 画像结构核验
- 匹配准确率验证思路：推荐结果与人工判断比对，说明当前达成情况和验证流程

## 第10页：演示流程
- Demo 账号：`demo@career.ai`
- 演示步骤：登录 → 上传简历 → 查看画像 → 岗位推荐 → 匹配详情 → 生成报告 → 查看图谱
- 展示重点：真实 API、真实数据、实时生成、可导出成果

## 第11页：创新亮点
- 四维评分模型提升匹配解释性
- 流式报告生成提升交互体验
- 岗位图谱辅助长期职业路径判断
- 双端设计满足学生使用与管理展示两种场景

## 第12页：落地价值与展望
- 可服务高校就业指导中心、职业规划课程、学生个人求职准备
- 下一步方向：多轮对话指导、个性化学习路线、更多行业岗位扩展
- 团队致谢与答辩 Q&A
