# 基于AI的大学生职业规划智能体 —— 项目概要介绍

## 一、项目背景与痛点

当前高校学生在职业规划阶段普遍面临四类典型问题。第一，自我认知模糊。很多学生对自己的专业能力、项目经历、软素养优势缺少系统梳理，往往只能凭主观印象判断“适合什么工作”，导致岗位定位偏差。第二，职业信息不对称。学生获取岗位信息的渠道分散，往往只能看到零散招聘启事，难以从大量真实岗位描述中总结出目标岗位的通用能力要求、技能组合和成长路径。第三，外部支持体系薄弱。传统职业指导往往集中在简历修改、宣讲会咨询等单点服务，难以做到一人一策、持续跟踪。第四，规划落地性差。即使学生知道自己想去什么方向，也常常不知道“差距在哪里”“先补什么”“多久能补到可投递状态”，最终职业规划停留在概念层面，缺乏可执行路径。

围绕这些痛点，我们认为职业规划不应只是一次性建议，而应是一套数据驱动、可解释、可迭代的智能决策流程。学生需要的不只是“推荐岗位”，更需要从画像生成、岗位理解、差距识别、行动建议到阶段复盘的完整闭环。

## 二、产品价值主张

本项目围绕“看清自己、看懂岗位、明确路径、持续优化”四个目标，构建了一套面向大学生的 AI 职业规划智能体。系统首先通过 AI 简历解析，将学生已有的教育背景、技能、项目、实习、证书、奖项和软素养证据结构化，生成可持续更新的学生画像。随后，系统基于近万条真实招聘数据沉淀岗位知识，抽象形成 51 类岗位画像，用真实市场需求而不是主观经验来刻画职业方向。

在匹配环节，系统采用基础要求、技术技能、职业素养、发展潜力四维评分模型，对学生与目标岗位之间的适配度进行量化拆解，不仅给出综合分，还明确指出“缺什么、影响多少、如何补齐”。在输出环节，系统自动生成五章结构化职业报告，将结果从单一评分升级为可解释的分析与行动方案。同时，Admin 端提供职业图谱可视化能力，直观展示岗位之间的垂直晋升和横向转岗关系，帮助学生从“当前可投递岗位”进一步看到“未来发展空间”。

## 三、系统架构

系统采用前后端分离架构。前端由 React + TypeScript 构建，分为 Admin 管理端与移动学生端两个入口。Admin 端服务于数据管理、岗位画像查看、图谱展示与运营演示；移动端则聚焦学生真实使用场景，包括登录、上传简历、查看画像、浏览推荐岗位、查看匹配详情、生成报告等完整流程。双端共享同一套后端 API，但在交互形态上分别针对管理视角与学生视角做了差异化设计。

后端采用 FastAPI，负责会话创建、简历解析、画像生成、推荐匹配、职业路径计算和报告导出等核心业务逻辑。数据层使用 PostgreSQL 16，并结合 pgvector 存储向量表示，用于技能相似度匹配与画像检索。AI 能力通过统一封装的 LLM/Embedding Provider 接入，支持 OpenAI 兼容接口配置，保证模型可替换、服务可迁移。系统同时支持 SSE 流式输出，在报告生成与解析状态回传时提供更平滑的实时反馈。整体设计强调模块化、可扩展与比赛展示可控性，便于后续继续扩展多轮对话、学习路径推荐和评估复盘能力。

## 四、核心功能演示说明

系统的核心演示流程从学生上传简历开始。学生在移动端输入邮箱或手机号建立轻量会话后，上传 PDF 或 Word 简历，系统通过流式接口实时反馈“文件提取”“AI 解析”“画像生成”等阶段进度，避免传统表单提交后的长时间无响应。简历解析完成后，系统自动生成学生画像页面，集中展示学校专业、竞争力评分、完整度、技术技能、项目经历、实习经历、证书荣誉以及待补全建议。若画像信息不完整，学生还可以进入补全对话页，针对系统提出的问题补充量化成果、协作经历和学习能力证据。

随后，系统基于已构建的岗位画像库为学生推荐匹配岗位。推荐列表不再只是岗位名称罗列，而是同时呈现综合分与四维细分得分，帮助学生快速理解自己更适合偏技术、偏数据还是偏产品方向。进入匹配详情页后，系统会展示基础、技能、素养、潜力四维分项分数，并列出差距清单，例如某项必备技能缺失、量化成果不足或软素养证据薄弱。学生不仅能看到当前是否适合该岗位，也能看到造成扣分的具体原因。

在此基础上，学生可以一键生成五章职业规划报告。系统通过 SSE 逐章返回“个人优势总结”“目标岗位分析”“差距与行动计划”“职业路径规划”“评估周期”等内容，移动端实时展示生成进度和已完成章节，提升互动感和完成感。报告完成后支持导出 HTML/PDF/Word 版本，便于课程作业、就业指导和比赛展示使用。

最后，在 Admin 端，评委和指导老师可以查看岗位图谱。图谱将各岗位按职级分层，用关系边展示晋升路径与换岗关系，帮助用户从单一岗位选择升级为职业发展视角的整体判断，也满足赛题对“至少 5 个岗位、每个岗位至少 2 条职业发展路径”的可视化验收要求。

## 五、创新亮点

第一，四维评分模型突出“可解释性”。很多同类产品只能给出一个模糊推荐结果，而本项目将人岗匹配拆解为基础要求、技能、素养和潜力四个维度，并保留差距项与建议文本，使结果不仅能看，还能指导行动。

第二，基于真实招聘数据构建岗位画像。系统不是使用抽象标签库虚拟岗位，而是从近万条招聘信息中提炼岗位共性要求，再聚合成结构化岗位画像，使推荐与分析更贴近真实就业市场。

第三，SSE 流式交互提升使用体验。从简历解析到报告生成，系统都尽量避免“提交后等待”的黑盒体验，而是将阶段状态、章节生成过程实时反馈给用户，让复杂 AI 任务在前端呈现为连续、可信的过程。

第四，职业图谱与报告联动。学生不仅能看到一个岗位适不适合自己，还能看到如果补齐短板，下一步可以往哪里发展，或者有哪些横向转岗方向。这使系统从“求职辅助工具”进一步升级为“职业发展导航系统”。

## 六、团队介绍

团队由产品、前端、后端与算法方向成员组成，具备完整的全栈协作能力。团队内部围绕“数据治理、后端服务、前端体验、AI 能力接入、比赛材料输出”进行分工，既能完成工程实现，也能围绕赛题要求进行验收优化和演示设计。团队在本项目中强调真实数据驱动、系统化架构和可落地展示，力求将职业规划从静态建议升级为面向大学生群体的可执行智能服务。
