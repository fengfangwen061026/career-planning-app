## 二、端到端流程验收

### 2.1 核心闭环测试（Must Pass）

**测试场景**：一个完整的学生使用流程

```
步骤 1: 上传简历
  - 操作: 上传一份 DOCX 测试简历
  - 预期: SSE 推送 5 步解析进度 → 完成后跳转画像页
  - PASS 条件: 15-30s 内完成，无报错

步骤 2: 查看学生画像
  - 操作: 进入画像页
  - 预期: 显示结构化画像（教育/技能/项目/证书/软素养）+ 完整度评分 + 竞争力评分
  - PASS 条件: 所有解析字段与简历原文一致，评分数值合理（0-100）

步骤 3: 岗位探索与匹配
  - 操作: 选择一个目标岗位（如"后端开发工程师"）
  - 预期: 显示四维雷达图 + 匹配总分 + 差距清单 + 每项差距的证据
  - PASS 条件: 四维分数均在 0-100，差距项有明确扣分原因

步骤 4: 查看职业路径
  - 操作: 在匹配结果页查看职业路径
  - 预期: 显示垂直晋升路径（≥3 个层级）+ 横向转岗路径（≥1 条）
  - PASS 条件: 路径节点显示岗位名 + 条件要求

步骤 5: 生成并导出报告
  - 操作: 点击"生成职业规划报告"
  - 预期: 骨架屏加载 → 报告内容逐章呈现 → 导出 PDF 按钮可用
  - PASS 条件: 报告包含 5 个必需章节，PDF 导出成功
```

## 三、准确率验证方案

### 3.1 岗位画像准确率验证（目标 ≥ 90%）

**方法**：
1. 随机抽取 5 个已生成的岗位画像
2. 对每个画像抽取 10 个关键信息点（必备技能 Top5 + 证书要求 + 学历要求 + 工作经验 + 薪资范围 + 核心职责）
3. 回溯对应岗位的全部 JD 原文，人工判定每个信息点是否准确
4. 准确率 = 准确信息点数 / 总信息点数（50个）

**PASS**: 准确率 ≥ 90%（即 ≤ 5 个信息点有误）

### 3.2 学生画像准确率验证（目标 ≥ 90%）

**方法**：
1. 准备 5 份已知内容的测试简历（内容预先人工标注）
2. 上传并解析，逐字段比对：教育信息、技能列表、项目经历、证书、软素养信号
3. 每份简历取 10 个关键信息点

**PASS**: 准确率 ≥ 90%

### 3.3 人岗匹配准确率验证（目标 ≥ 80%）

**方法**：
1. 选择 5 组 (学生画像, 目标岗位) 配对
2. 人工标注每组的关键技能匹配情况（匹配/不匹配/部分匹配）
3. 对比系统的技能匹配判定结果

**PASS**: 匹配准确率 ≥ 80%
